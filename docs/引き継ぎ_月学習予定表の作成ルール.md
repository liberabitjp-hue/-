# 引き継ぎ仕様: 月学習予定表（5年2組）の作り方

新しいセッションで、これまでと同じやり方で月学習予定表（時間割）を作るための仕様です。
令和8年10月・11月の作成と、利用者（5年2組担任）とのやり取りで決まったことをまとめています。

- **利用者の指示は、指示書（`docs/specs/`）や一般的な教育上の推測より優先します。**
- 迷ったら この資料 → `tools/README.md`（日ごとの判断理由）→ `docs/specs/初回開発指示書.md` の順に確認します。
- 最終更新: 2026年11月（12月分の初期案まで作成。利用者の確認待ち）

## 2. 道具

| ファイル | 役割 | 使い方 |
|---|---|---|
| `tools/<月>-plan.py` | 月ごとの配置スクリプト。枠を層の順に確定し、単元・進度を振り、点検結果を表示する | `python3 tools/november-plan.py` |
| `tools/data/class1-<月>.txt` | 5年1組の学習予定表の書き起こし（紫のセルに `*`） | 3.3 の書式 |
| `tools/check-class1.py` | 2組の配置を1組の表と1コマずつ突き合わせる | `python3 tools/check-class1.py tools/november-plan.py tools/data/class1-11月.txt` |
| `tools/annual-plan.cjs` | 年間指導計画から、指定した月の単元配当を表示する | `node tools/annual-plan.cjs 12`（教科を絞るなら `node tools/annual-plan.cjs 12 算数`） |
| `tools/progress-end.py` | 配置スクリプトの月末の進度を表示する（翌月の書き出し位置） | `python3 tools/progress-end.py tools/november-plan.py` |
| `tools/write-plan.py` | 配置をひな型の月シートへ書き込み、xlsmを作る | `python3 tools/write-plan.py 出力.xlsm tools/october-plan.py:10月 tools/november-plan.py:11月` |
| `tools/verify-output.cjs` | 書き出したxlsmの過不足と下校時刻の表示を検算する | `node tools/verify-output.cjs 出力.xlsm 10月 11月` |
| `tools/compare-template.py` | ひな型から変わったパートと、VBAマクロが元のままかを確かめる | `python3 tools/compare-template.py 出力.xlsm` |

`.cjs` の道具は `app/node_modules` の SheetJS を使います。セッション開始時のフックで
`app/` に `npm install` 済みのはずです。無ければ `cd app && npm install`。

## 3. 新しい月の作り方（手順）

### 3.1 資料を集める（利用者から受け取る。多くは写真）

| 資料 | 使う所 | 無いとき |
|---|---|---|
| **授業時数･下校予定時刻一覧表**（その月。版番号を確認し最新版を使う） | 授業日・5学年の時数・下校時刻・行事・今月の留意点 | 必須。依頼する |
| **5年1組の学習予定表**（その月） | 紫色のセル・行事・家庭科の時間・時数の目標（計画欄） | 必須。依頼する |
| **学習予定表 外国語**（渡部先生、その月） | 5-2の外国語の枠（黄色の蛍光ペンの枠） | 依頼する。無ければ前月パターンで仮置きし報告 |
| 通級の固定時間割表 | 通級で児童が抜ける枠 | 12月は「R8 通級II 固定時間割表（12月）改訂版」（月5算・火2国・水3算・水5国）。1月以降は新しい表を依頼 |
| 前月の確定版（実際に使った予定表） | 翌月の進度の開始位置 | 無ければ前月の配置スクリプトの進度で続ける（3.5） |
| 利用者の指示（出張日・行事の扱いなど） | 利用者指定の枠 | 指示どおり |

写真は、集計欄などで**読み取りを検算してから**使います（1組の表は書き起こしを集計して1組の集計欄と比べる）。

### 3.2 配置スクリプトを作る

前月のスクリプトをコピーして `tools/<月>-plan.py`（例: `december-plan.py`）を作り、
上から順に書き換えます。各設定とその埋め方:

| 設定 | 何を書くか | 資料 |
|---|---|---|
| `DAYS` | `(日, 曜日, 5学年の時数)` を授業日ぶん | 授業時数･下校予定時刻一覧表の**5学年列** |
| `DISMISSAL` | `日: '時:分'`（5学年の下校時刻） | 同上 |
| `EVENTS` | `(日, 校時): (教科, 下段の行事名)`。丸数字＝実施校時、`行1`→行事、`児1`→児童会、`ク1`→クラブ、`学1`→学活 | 同上の行事欄・留意点 |
| `USER_FIXED` | 利用者が日・校時・教科を指定した枠 | 利用者の指示 |
| `HOKYO` | 担任出張日に、どうしても埋まらない枠（補教の先生が担任教科） | 4章の出張日ルール |
| `BUNKA_FIXED` | 外国語の枠（5-2の分） | 学習予定表 外国語 |
| `GRADE_ALIGN` | 1組の紫色のセルと同じ `(日, 校時): 教科` | 1組の学習予定表 |
| `PRESENTATION_DAY` など | 発表会の日など、1組と同じ教科で数える日 | 1組の学習予定表 |
| `KATEI` | 2組の家庭科の枠と下段（「1組図工」/「舞子先生の案による」） | 1組の表で1組担任が空く時間（4章） |
| `SOGO` | 総合の枠ごとの系列名と活動 | 1組の表の書き込み・年間指導計画 |
| `RIKA_MOVE` | 上の層で固定枠が埋まった理科の振替先 | R8固定時間割で佐藤先生が空く校時 |
| `NO_BASE` | 基本パターンを使えない枠（1組の分科と重なる等） | |
| `BASE` | 曜日×校時の基本パターン（4.2）。通常は変えない | |
| `ADJUST` | 時数・ルールを満たすための差し替え。**必ず理由を書く** | |
| `TARGET` | 教科ごとの目標時数＝**1組の表の「計画」欄**（国語は書写を除いた数、書写は別に） | 1組の学習予定表 |
| `UNITS` | 教科ごとの単元・進度の列（月の時数ぶん） | 年間指導計画（3.5） |
| `NOTES` | 備考欄（【短】・弁当日・行事など5年2組に関係するもの） | 授業時数･下校予定時刻一覧表 |
| `TRIP_DAYS` / `CLASS1_BUNKA` | 担任出張日と、その日に1組が分科の校時 | 利用者の指示・1組の表 |
| `TSUKYU` | 通級の枠 | 通級の固定時間割表 |
| `KOME_START` など | 総合の系列の開始進度 | 前月の進度 |

`python3 tools/<月>-plan.py` を実行すると、目標との差・日ごとの配置・各点検の結果が出ます。
基本パターンから外国語・家庭・総合・体育を埋めようとするとエラーになるので、その枠は上の層か
`ADJUST` で埋めます。

### 3.3 1組の書き起こしを作る

`tools/data/class1-<月>.txt` に、1組の表を1日1行で書き起こします。

```
# 行頭 # はコメント
2 国語 理科 総合* 書写 外国語* 算数
24 音楽 図工 図工 ? 社会
```

- 紫色のセル（2組と合わせる枠）は教科名の後ろに `*`。学年合同の外国語にも `*`。
- 「5-1単独体育」「5-2単独体育」と書かれた枠は合わせないので `*` を付けない。
- 読み取れない・未定の枠は `?`。利用者の訂正はコメントに残す。

### 3.4 点検して直す

1. `python3 tools/<月>-plan.py`: 目標との差がすべて0で、同じ日に同じ教科・分科・出張日の点検が
   「なし」になるまで `ADJUST` などを直す。通級は合わない枠を一覧で報告する（4章）。
2. `python3 tools/check-class1.py tools/<月>-plan.py tools/data/class1-<月>.txt`: 「重複・ずれ なし」になるまで直す。
   表示される1組の時数が、1組の集計欄の計画と一致することも確かめる。

### 3.5 単元・進度を振る

1. 前月の終わりの位置を確かめる: `python3 tools/progress-end.py tools/<前月>-plan.py`
   （前月の確定版を受け取っていれば、そちらの進度を優先する）。
2. 月の配当を確かめる: `node tools/annual-plan.cjs <月>`
   - B列＝単元名、D列＝単元の計画時数、F列の `(n)`＝**その月に配当する時数**（残りは翌月先頭の繰越欄）、
     H列＝月計。月の先頭行の `(n)` は前月からの繰越。
   - 学活は単元名がD列。総合は系列（本宮の米／まゆみ小の伝統（鼓笛）／東日本大震災）が横に並ぶ。
3. `UNITS` に、前月の続きから月の時数ぶんの単元・進度を並べる（`seq(単元, 開始, 分母, 時間数)`）。
   時数が年間計画の配当とずれる分は、最後の単元を増減して合わせ、報告する。
4. 体育・総合など利用者が順序や単元を指定したものは、指定に従う（例: 11月の体育は跳び箱3/5から）。

### 3.6 書き出して検算する

```bash
python3 tools/write-plan.py 出力.xlsm tools/october-plan.py:10月 tools/november-plan.py:11月 tools/december-plan.py:12月
node tools/verify-output.cjs 出力.xlsm 10月 11月 12月
python3 tools/compare-template.py 出力.xlsm
```

- 過不足が1組の表と同じになっていること、下校時刻が文字列 `15:45` の形になっていることを確かめる。
- 変わったパートが書き込んだ月シートだけで、VBAマクロが元のままであること。

### 3.7 報告・保存

- xlsmを送る（ファイル名は同じにして上書きで渡す）。
- 配置スクリプト・書き起こしデータ・`tools/README.md`（日ごとの判断理由と確認事項）を更新し、
  コミットしてプッシュする。月が仕上がったら、利用者に了承を得てプルリクエストで既定のブランチへ取り込む
  （次のセッションが続きから始められるように）。
- 報告の形は8章。

### 3.8 修正依頼を受けたとき

- 指定された枠を `USER_FIXED`（または該当する層）に入れ、崩れた時数を `ADJUST` で戻す。
- 3.4 の点検と 3.6 の検算をやり直し、**変更前→変更後の表**で報告する。
- 「取り消し」と言われたら、その部分だけを元に戻し、ほかの修正は残す。
- 初案から何が変わったかを聞かれたら、`git show <初案のコミット>:tools/<月>-plan.py` と現在の配置を
  1コマずつ比べて、教科が変わった日と単元・進度だけ変わった日を分けて答える。

## 4. 配置のルール

### 4.1 枠を確定する優先順位（上ほど優先）

| 順 | 層 | 内容 |
|---|---|---|
| 1 | 利用可能な日・校時 | 授業時数･下校予定時刻一覧表の5学年列 |
| 2 | 行事 | 同表の行事欄・今月の留意点 |
| 3 | 利用者指定 | 利用者が日・校時・教科を指定した枠。何より優先 |
| 4 | 分科の確定枠 | 外国語（渡部先生の予定表の5-2の枠）。変更不可 |
| 5 | 学年で合わせる枠 | 1組の予定表の紫色のセルと行事 |
| 6 | 家庭科 | 1組担任の手が空く時間 |
| 7 | 分科の振替 | 上の層で固定枠が埋まった理科などを、担当の先生の空き時間へ |
| 8 | 調整 | 時数・ルールを満たすための差し替え（理由を必ず書く） |
| 9 | 前月パターン | 曜日×校時の基本パターン |

### 4.2 基本パターン（9月確定版の最頻値。R8固定時間割で同数を解消）

| | ① | ② | ③ | ④ | ⑤ | ⑥ |
|---|---|---|---|---|---|---|
| 月 | 図工 | 図工 | 国語 | 算数 | 学活 | － |
| 火 | 社会 | 国語 | 算数 | 理科 | 体育 | 総合 |
| 水 | 社会 | 理科 | 算数 | 算数 | 国語 | 総合 |
| 木 | 理科 | 外国語 | 書写 | 音楽 | 体育 | 総合 |
| 金 | 外国語 | 算数 | 家庭 | 家庭 | 道徳 | － |

### 4.3 利用者の指示で確定したルール

**学年で合わせる**
- 1組の予定表の**紫色のセルと行事は、同じ日・同じ校時に合わせる**。「5-1単独体育」「5-2単独体育」は合わせない。
- **時数は1組の表の「計画」欄に揃える**（5章）。

**分科（外国語・理科・書写）**
- **同じ分科の教科は1日1時間まで**（理科②理科③も、理科①理科④も不可）。
- **教科が違えば続けてよい**（理科①外国語②は可）。
- 外国語は渡部先生の予定表の枠だけに置く。資料に無い枠には置かない。
- 理科（佐藤（和）先生）の5-2の固定枠は火4・水2・木1。動かすときは、R8固定時間割で佐藤先生が空いている
  校時へ置き、1組の理科と重ねない（佐藤先生は金5に6-1を持つ）。
- 書写（教務・大浦先生）の5-2の固定枠は木3。

**家庭科（交換授業）**
- 5-2の家庭科は1組担任が受け持つ。**1組が図工・外国語・理科・書写の時間にしか置けない。**
- 1組が図工の時間は2組担任が1組の図工を受け持つので、2組は家庭（または分科）にする。
- 1組が家庭科の時間に2組の家庭科は置かない（家庭科室が重なる）。

**同じ日に同じ教科**
- **図工・家庭を除き、同じ日に同じ教科を2時間以上置かない**（時数上どうしても難しい場合のみ可）。
- 行事・学年合わせの枠（校内発表会、学年の総合など）は動かせないため対象外。
- 解消には、算数などを「その教科が無い日」の担任教科と入れ替える。単純な入れ替えで解けないときは
  3つの枠を順に回す（11月の11日④算数→26日④、26日④音楽→11日⑥、11日⑥道徳→11日④ のように）。

**担任の出張日**
- **2組担任の教科（音楽・道徳・国語など）は置かない。**
- 置けるのは、分科、学年合同の枠、1組が分科の時間に1組担任が受け持つ授業だけ。
- それでも埋まらない枠は、**補教の先生が担任教科**を受け持つ（音楽・道徳は不可）。

**通級**（10・11月は R8 通級II 固定時間割表 10・11・12月、12月は 12月改訂版）
- 5-2の児童が抜ける枠: 10・11月は **火2＝国語、水3＝算数、水5＝国語、金2＝算数**、12月は **月5＝算数、火2＝国語、水3＝算数、水5＝国語**。この校時には該当教科を置く。
- 通級表の注記どおり、**行事・外国語・水泳等はこちらが優先**。
- 1組と合わせる枠や利用者指定の枠とぶつかる場合は、無理に動かさず一覧で報告する
  （利用者が残すと決めた枠は残す。例: 11月13日②の家庭）。

**その他**
- 下校時刻は授業時数･下校予定時刻一覧表の**5学年**の時刻を、文字列 `15:45` の形で入れる（1回でコピー＆貼り付けできるように）。
- 体育館が使えない期間（行事準備など）に体育館の運動（跳び箱など）が入る場合は報告する。
- 体育の単元名や順序は利用者の指示に従う（11月: サッカー→タッチフットボールに変更、跳び箱3/5から、跳び箱の後にタッチフットボール）。

### 4.4 毎回の点検

| 点検 | 内容 | どこで |
|---|---|---|
| 時数 | 全教科が `TARGET` どおりか | 配置スクリプト |
| 同じ日に同じ教科 | 図工・家庭以外で2時間以上の日がないか | 配置スクリプト `check_same_day` |
| 分科 | 同じ分科の教科が1日2時間以上の日がないか | 配置スクリプト `check_bunka_runs` |
| 出張日 | 担任の教科が入っていないか（補教の枠を除く）、音楽・道徳がないか | 配置スクリプト `check_trip` |
| 通級 | 通級の枠に想定教科が入っているか | 配置スクリプト `check_tsukyu` |
| 1組との突き合わせ | 紫・行事のずれ、先生・特別教室の重複、家庭科・図工の交換 | `check-class1.py` |
| 出力 | 過不足・下校時刻の表示・VBAマクロ | `verify-output.cjs`・`compare-template.py` |

## 5. 時数の考え方

- 目標は**5年1組の予定表の「計画」欄と同じ数字**（利用者指示）。
- **予定表シート（利用者の入力値）は変えない。** その結果、過不足が出てもよい。
  - 10月: 国語−1・算数−1・総合+2・児童会+1、合計114（予定113）
  - 11月: 国語+1・算数+1・総合−2・児童会+1、合計102（予定101）
- **国語の時数には書写を含む**（集計数式が `COUNTIF(…,"国語")+COUNTIF(…,"書写")`）。
- 行事（時）の集計対象は教科名 `行事`、行事（日）は `①行事`。
- 書写は年間計画の月の配当に合わせる（11月は3時間）。

## 6. 書き方の約束（xlsmの月シート）

| 欄 | 書き方 |
|---|---|
| 教科（上段） | 教科名。行事は `行事`、児童会・クラブはそのまま |
| 進度（上段右） | `n/m` を**文字列**で（Excelの日付誤変換を防ぐ） |
| 単元（下段） | 年間指導計画の単元名 |
| 分科の下段 | 理科「佐藤（和）先生の案による」、外国語「渡部先生の案による」、書写「大浦先生の案による」。進度は空欄 |
| 家庭の下段 | 1組が図工の時間は「1組図工」、それ以外は「舞子先生の案による」。調理実習などは利用者の指示どおり |
| 総合の下段 | 系列名「本宮の米を全国に発信しよう」（n/42）、「東日本大震災からつながる現在」（n/20）、鼓笛は「鼓笛」（進度なし） |
| 行事の下段 | 行事名（校内発表会、第2回避難訓練 など） |
| 備考（Q列） | 【短】・弁当日・行事など、5年2組に関係するものを抜粋 |
