# 引き継ぎ資料: 月学習予定表（5年2組）の作成ルール

新しいセッションで作業を続けるための資料です。令和8年10月・11月の作成と、利用者
（5年2組担任）とのやり取りで決まったルールをまとめています。**利用者の指示は、指示書や
一般的な教育上の推測より優先します。** ルールに迷ったら、この資料 → `tools/README.md`
→ `docs/specs/初回開発指示書.md` の順に確認してください。

最終更新: 2026年10月27日（11月分を作成・修正済み）

## 2. 毎月の作業の流れ

1. **資料を受け取る**（多くは写真）。届いたら内容を読み取り、配置スクリプトへ直接書き起こす。
2. **前月の配置スクリプトをコピーして新しい月を作る**（`tools/<月>-plan.py`）。
3. **層の順に枠を確定する**（3章）。各枠に「由来」（行事・分科確定・学年合わせ・利用者指定・
   調整・前月パターンなど）を付ける。
4. **時数を1組の表の数字に合わせる**（5章）。
5. **点検をすべて通す**（6章）。
6. **1組の時間割と1コマずつ突き合わせる**: 先生・教室の重複、紫のセルのずれ、行事のずれがないか。
7. **書き出す**: `python3 tools/write-plan.py 出力.xlsm tools/october-plan.py:10月 tools/november-plan.py:11月 …`
8. **確認する**: 書き出したxlsmを読み直し、集計欄の過不足と下校時刻を確かめる。
9. **報告する**（8章の形式）。xlsmを送り、変更をコミット・プッシュする。

## 3. 枠を確定する優先順位（上ほど優先）

| 順 | 層 | 内容 |
|---|---|---|
| 1 | 利用可能な日・校時 | 授業時数･下校予定時刻一覧表の**5学年列**（最新版を使う。版番号を確認） |
| 2 | 行事 | 同表の行事欄・今月の留意点 |
| 3 | 利用者指定 | 利用者が日・校時・教科を指定した枠。何より優先 |
| 4 | 分科の確定枠 | 外国語（渡部先生の月の予定表で5-2の枠）。変更不可 |
| 5 | 学年で合わせる枠 | **5年1組の予定表の紫色のセル**（体育・総合・学活など）と行事 |
| 6 | 家庭科 | 1組担任の手が空く時間（4章） |
| 7 | 分科の振替 | 上の層で固定枠が埋まった理科などを、担当の先生の空き時間へ |
| 8 | 調整 | 時数・各ルールを満たすための差し替え（理由を必ず書く） |

## 4. 守るルール（利用者の指示で確定したもの）

### 学年で合わせる
- **5年1組の予定表の紫色のセルと行事は、同じ日・同じ校時に合わせる。**
  1組の表に「5-2単独体育」「5-1単独体育」とあれば、その日はそれぞれ単独（合わせない）。
- **時数の過不足は1組の表の数字に揃える**（5章）。

### 分科（外国語・理科・書写）
- **同じ分科の教科は1日1時間まで**（理科②理科③も、理科①理科④も不可）。
- **教科が違えば続けてよい**（理科①外国語②は可）。
- 外国語は渡部先生の予定表の枠だけに置く。資料に無い枠には置かない。
- 理科（佐藤（和）先生）の5-2の固定枠は火4・水2・木1。動かす場合は、R8固定時間割で
  佐藤先生が空いている校時へ置き、1組の理科と重ねない（佐藤先生は金5に6-1を持つ）。
- 書写（教務・大浦先生）の5-2の固定枠は木3。

### 家庭科（交換授業）
- **5-2の家庭科は1組担任が受け持つ。** 1組担任の手が空く時間
  （1組が図工・外国語・理科・書写）にしか置けない。
- 1組が図工の時間は2組担任が1組の図工を受け持つので、2組は家庭（または分科）にする。
- 1組が家庭科の時間に2組の家庭科は置かない（家庭科室が重なる）。

### 同じ日に同じ教科
- **図工・家庭を除き、同じ日に同じ教科を2時間以上置かない**（時数上どうしても難しい場合のみ可）。
- 行事・学年合わせの枠（校内発表会、学年の総合など）は動かせないため対象外。

### 担任の出張日
- **2組担任の教科（音楽・道徳・国語など）は置かない。**
- 置けるのは、分科、学年合同の枠、1組が分科の時間に1組担任が受け持つ授業だけ。
- それでも埋まらない枠は、**補教の先生が担任教科**を受け持つ（音楽・道徳は不可）。

### 通級（R8 通級II 固定時間割表 10・11・12月）
- 5-2の児童が抜ける枠: **火2＝国語、水3＝算数、水5＝国語、金2＝算数**。
  この校時には該当教科を置く（児童が他教科を欠かずに済む）。
- 通級表の注記どおり、**行事・外国語・水泳等はこちらが優先**。
- 1組と合わせる枠や利用者指定の枠とぶつかる場合は、無理に動かさず一覧で報告する。

### 時刻・その他
- 下校時刻は授業時数･下校予定時刻一覧表の**5学年**の時刻を入れる。
- 体育館が使えない期間（行事準備など）に体育館の運動（跳び箱など）が入る場合は報告する。

## 5. 時数の考え方

- 目標は**5年1組の予定表の「計画」欄と同じ数字**（利用者指示）。
- **予定表シート（利用者の入力値）は変えない。** その結果、過不足が出てもよい
  （10月: 国語−1・算数−1・総合+2・児童会+1、合計114／11月: 国語+1・算数+1・総合−2・
  児童会+1、合計102。どちらも1組と同じ）。
- **国語の時数には書写を含む**（集計数式が `COUNTIF(…,"国語")+COUNTIF(…,"書写")`）。
- 行事（時）の集計対象は教科名 `行事`、行事（日）は `①行事`。
- 年間指導計画の月別配当で、単元行の `(n)` は**その月に配当する時数**（残りは翌月の繰越欄）。

## 6. 毎回の点検（配置スクリプトが表示する）

| 点検 | 内容 | 関数・設定 |
|---|---|---|
| 時数 | 全教科が目標どおりか | `TARGET` |
| 同じ日に同じ教科 | 図工・家庭以外で2時間以上の日がないか | `check_same_day` |
| 分科 | 同じ分科の教科が1日2時間以上の日がないか | `check_bunka_runs` |
| 出張日 | 担任の教科が入っていないか（補教の枠を除く） | `TRIP_DAYS`・`CLASS1_BUNKA`・`HOKYO` |
| 通級 | 通級の枠に想定教科が入っているか | `TSUKYU` |

スクリプトの外で行う確認:
- 1組の時間割を書き起こして突き合わせる。書き起こした1組の表を集計すると、1組の集計欄と
  一致するはずです（読み取りが正しい証拠になる）。
- 書き出したxlsmを読み直し、集計欄の過不足・下校時刻（h:mm表示）を確かめる。

## 7. 書き方の約束（xlsmの月シート）

| 欄 | 書き方 |
|---|---|
| 教科（上段） | 教科名。行事は `行事`、児童会・クラブはそのまま |
| 進度（上段右） | `n/m` を**文字列**で（Excelの日付誤変換を防ぐ） |
| 単元（下段） | 年間指導計画の単元名 |
| 分科の下段 | 理科「佐藤（和）先生の案による」、外国語「渡部先生の案による」、書写「大浦先生の案による」。進度は空欄 |
| 家庭の下段 | 1組が図工の時間は「1組図工」、それ以外は「舞子先生の案による」。調理実習などは利用者の指示どおり |
| 総合の下段 | 系列名「本宮の米を全国に発信しよう」（n/42）、「東日本大震災からつながる現在」（n/20）、鼓笛は「鼓笛」（進度なし） |
| 行事の下段 | 行事名（校内発表会、第2回避難訓練 など） |
| 備考（Q列） | 【短】・弁当日・行事など、5年2組に関係するものを抜粋 |
| 下校時刻 | 右側の別表 **AL列**「下校時刻」に時刻の数値（h:mm 書式） |

`write-plan.py` はシートXMLを直接書き換えるので、セル書式・数式・他シート・VBAマクロは
変わりません。**リポジトリのひな型 `app/test-fixtures/output-template.xlsm` はセルの書式
（罫線・塗り）が落ちています。** 書式つきの原本を利用者から受け取れたら、そちらに書き込む。

## 8. 利用者とのやり取りの約束

- **日本語**で、です・ます調。表で「変更前→変更後」を示す。
- 修正のたびに**xlsmを送り直す**（ファイル名は同じ）。スクリプト・READMEはコミットしてプッシュ。
- **確認事項は最後に番号つきで**。推測で決めた枠（担当の先生の空き時間など）は必ず挙げる。
- **指示があいまいで、解釈によって結果が大きく変わるときは、作業前に選択肢で確認する。**
  （例: 「分科の連続NG」が同じ教科か別教科も含むか、で結果が変わった）
- 利用者の指示どうしが両立しないときは、新しい指示を優先し、崩れたものを報告する。
- 利用者が「取り消し」と言ったら、その部分だけを元に戻し、ほかの修正は残す。
- 写真の資料は、集計欄などで読み取りを検算してから使う。
