# tools/ — フェーズ2の下ごしらえ（作業用スクリプト）

アプリ本体（`app/`）ではなく、**フェーズ2の生成ロジックを実装する前に、
実データ1か月分で手順を確定させるため**に使った作業用スクリプトです。
令和8年10月の5年2組を対象に、指示書14章の段階どおりに初期案を組み立てます。

| ファイル | 役割 |
|---|---|
| `october-plan.py` | 10月の配置（教科・単元・進度）を組み立て、予定表の月別予定時数と照合する |
| `write-october.py` | 組み立てた結果を `output-template.xlsm` の「10月」シートへ書き込む |

```bash
python3 tools/october-plan.py                    # 配置を組み立てて過不足を表示
python3 tools/write-october.py 出力先.xlsm        # 記入済みのxlsmを書き出す
```

`write-october.py` はシートXMLを直接書き換えます。SheetJSでの書き出しは
セル書式を落とすため使っていません。この方式なら、セル書式・数式・
他の月のシート・VBAマクロ（`xl/vbaProject.bin`）が一切変わりません
（`xl/worksheets/sheet7.xml` 以外のパートはバイト単位で同一）。
進度は `t="str"` の文字列として書き込みます（指示書11章、Excelでの日付誤変換を防ぐため）。

## 使った資料

`app/test-fixtures/` の5ファイルに加えて、あとから受け取った紙資料3点を
スクリプト内に直接書き起こしている（Excelで受け取れるようになったら取込みへ移す）。

| 資料 | 反映内容 |
|---|---|
| 授業時数･下校予定時刻一覧表 10月 **(9/17版)** | 10/5の上学年に6校時（児童会活動日＝委員会活動）が追加され、5学年の実施できる時数が113→114になった |
| **R8 通級II 固定時間割表（10・11・12月）** | 5-2の児童が抜ける枠。火2=国語、水3=算数、水5=国語、金2=算数。この校時に該当教科を置くと児童が他教科を欠かずに済む |
| **10月 学習予定表 外国語**（渡部先生） | 5-2の外国語8コマの確定割当。指示書12.2により変更不可の固定枠として扱う |

## ここで確定した判断基準（フェーズ2の実装仕様）

- **分科の確定枠が最優先**: 分科担当者の翌月割当を取り込めた教科は、前月パターンより
  優先して固定する（指示書12.2）。資料が無い教科（理科・書写・家庭）のみ前月パターンで補う。
  基本パターンに外国語の枠があっても分科資料に割当てが無ければ**埋めずにエラーにする**
  （前月の癖で存在しない授業を作らないため）。
- **前月パターン**: 9月確定版の曜日×校時の最頻値を基本とし、同数で割れた枠は
  R8固定時間割の特別教室欄・分科欄で解消する（例: 木1は算数と理科が各2回だが、
  固定時間割が理科室=5-2・佐藤和=5-2理なので理科を採る）。
- **通級の枠は点検項目**: 通級表で児童が抜ける校時に想定教科が入っているかを毎回点検し、
  違う場合は一覧で示す（行事が入る場合は行事を優先してよい）。
- **行事の解釈**: 丸数字＝実施校時、`行1`/`学1`/`児1`/`ク1`＝時数区分。
  対象学年は `全`・`上`（4〜6年）を5年の対象、`低`・他学年指定を対象外とする。
  校時指定のない `ク1` は前月と同じ6校時へ置き、確認対象として示す。
- **時数調整**: 予定表（月案側）の月別予定時数を最優先とし、差が全て0になるまで
  基本パターンの枠を差し替える。差し替えた枠は理由を保持して表示する。
- **授業時数表が予定表より新しい場合**: 実施できる時数が変わったら予定表側を直す。
  10月は10/5の委員会活動が増えた分、予定表の児童会を1→2にした（`PLAN_FIXES`）。
- **単元・進度**: 年間指導計画の月別配当表を使う。単元行の `(n)` は
  **その月に配当する時数**で、残りは翌月先頭の繰越欄と一致する（4〜9月の実績で検証済み）。
  進度は前月確定版の続きから振り、年間計画上の理論値と食い違う場合は前月確定版を優先する。
- **国語の時数には書写を含む**（出力先ひな型の集計数式が
  `COUNTIF(...,"国語")+COUNTIF(...,"書写")` になっている）。
- **行事（時）の集計対象は教科名 `行事`、行事（日）は `①行事`**。

## 令和8年10月で利用者に確認が必要な点

1. 理科をどの日で1時間減らすか（10/8木1にした。分科担当者の都合で決まるため）
2. 書写をどの木3に置くか（10/15・10/29にした。月2時間に対し木3は5回ある）
3. 10/21③のまゆみっ子ランニングチャレンジを体育1時間として数えてよいか
   （この校時は通級の算数枠と重なる。通級表は行事優先とあるのでそのままにしている）
4. 10/19(月)1・2校時が国語2時間続きになること
5. 家庭の下段「1組図工」を10月も踏襲してよいか
6. 総合の順序（東日本大震災3時間を先、稲刈り・脱穀5時間を後にしている）
