# tools/ — フェーズ2の下ごしらえ（作業用スクリプト）

アプリ本体（`app/`）ではなく、**フェーズ2の生成ロジックを実装する前に、
実データ1か月分で手順を確定させるため**に使った作業用スクリプトです。
令和8年10月・11月の5年2組を対象に、指示書14章の段階どおりに初期案を組み立てます。

| ファイル | 役割 |
|---|---|
| `october-plan.py` | 10月の配置（教科・単元・進度）を組み立て、目標時数と照合する |
| `november-plan.py` | 11月の配置。10月の初期案の進度の続きから振る |
| `write-plan.py` | 組み立てた結果を `output-template.xlsm` の各月シートへ書き込む |

```bash
python3 tools/october-plan.py                    # 配置を組み立てて過不足を表示
python3 tools/write-plan.py 出力先.xlsm tools/october-plan.py:10月 tools/november-plan.py:11月
```

`write-plan.py` はシートXMLを直接書き換えます。下校時刻は各配置スクリプトの `DISMISSAL`
（授業時数･下校予定時刻一覧表の5学年列）を、月シート右側の別表のAL列「下校時刻」へ
9月までと同じく時刻の数値で入れます。

**注意**: リポジトリのサンプル `app/test-fixtures/output-template.xlsm` は、メタデータを
消したときにセルの書式（罫線・塗り・表示形式）がすべて落ちている（styles.xml の
cellXfs が1つだけ）。そのため書き出したブックも罫線などの無い表になる。下校時刻だけは
小数で表示されないよう、ブックにある時刻書式 `h:mm` の cellXfs を1つ足して当てている。
書式つきの原本に書き込む場合も、既存の書式には手を付けない。

SheetJSでの書き出しは
セル書式を落とすため使っていません。この方式なら、セル書式・数式・
他の月のシート・VBAマクロ（`xl/vbaProject.bin`）が一切変わりません
（書き込んだ月シート以外のパートはバイト単位で同一）。
進度は `t="str"` の文字列として書き込みます（指示書11章、Excelでの日付誤変換を防ぐため）。

11月分は、授業時数･下校予定時刻一覧表 11月（10/9版）、11月 学習予定表 外国語（渡部先生）、
5年1組 11月 学習予定表の紫色のセルと行事を使った。

`app/test-fixtures/` の5ファイルに加えて、あとから受け取った紙資料3点を
スクリプト内に直接書き起こしている（Excelで受け取れるようになったら取込みへ移す）。

| 資料 | 反映内容 |
|---|---|
| 授業時数･下校予定時刻一覧表 10月 **(9/17版)** | 10/5の上学年に6校時（児童会活動日＝委員会活動）が追加され、5学年の実施できる時数が113→114になった |
| **R8 通級II 固定時間割表（10・11・12月）** | 5-2の児童が抜ける枠。火2=国語、水3=算数、水5=国語、金2=算数。この校時に該当教科を置くと児童が他教科を欠かずに済む |

## ここで確定した判断基準（フェーズ2の実装仕様）

- **分科の確定枠が最優先**: 分科担当者の翌月割当を取り込めた教科は、前月パターンより
  優先して固定する（指示書12.2）。資料が無い教科（理科・書写・家庭）のみ前月パターンで補う。
  基本パターンに外国語の枠があっても分科資料に割当てが無ければ**埋めずにエラーにする**
  （前月の癖で存在しない授業を作らないため）。
- **前月パターン**: 9月確定版の曜日×校時の最頻値を基本とし、同数で割れた枠は
  R8固定時間割の特別教室欄・分科欄で解消する（例: 木1は算数と理科が各2回だが、
  固定時間割が理科室=5-2・佐藤和=5-2理なので理科を採る）。
- **通級の枠は点検項目**: 通級表で児童が抜ける校時に想定教科が入っているかを毎回点検し、
  違う場合は一覧で示す（行事が入る場合は行事を優先してよい）。
- **行事の解釈**: 丸数字＝実施校時、`行1`/`学1`/`児1`/`ク1`＝時数区分。
  対象学年は `全`・`上`（4〜6年）を5年の対象、`低`・他学年指定を対象外とする。
  校時指定のない `ク1` は前月と同じ6校時へ置き、確認対象として示す。
- **時数調整**: 予定表（月案側）の月別予定時数を最優先とし、差が全て0になるまで
  基本パターンの枠を差し替える。差し替えた枠は理由を保持して表示する。
- **学年で合わせる枠は分科の次に優先**: 同学年の他学級と合同・共用の枠（学年体育、
  学年総合、交換授業の家庭科・図工）は、前月パターンより先に確定させる。
  合わせた結果、分科の固定枠（例: 水2の理科）と重なった場合は、分科担当者の
  固定時間割で空いている校時へ振り替える（10月は7日・14日の理科を水6へ）。
- **交換授業の家庭科**: 5-2の家庭科は1組担任が受け持つ。1組担任の手が空く時間
  （1組が図工・外国語・理科・書写）にしか置けず、1組が家庭科の時間とは重ねない。
- **分科の同じ教科を2時間続けない**（書写の2時間続きは不可）。同じ日に2時間入れる場合は
  別の教科をはさむ。配置スクリプトの `check_bunka_runs` で毎回点検する。
- **担任の出張日**: 2組担任の教科（音楽・道徳・国語など）は置かない。置けるのは
  分科（外国語・理科・書写）、学年合同の枠、そして1組が分科の時間に1組担任が受け持つ授業
  （家庭など）だけ。配置スクリプトの `TRIP_DAYS` と `CLASS1_BUNKA` で毎回点検する。
- **時数の過不足は学年で揃える**: 予定表シートは利用者の入力値なので変えない。
  10月は1組の表と同じく、予定113に対して計画114（国語-1、算数-1、総合+2、児童会+1）。
- **単元・進度**: 年間指導計画の月別配当表を使う。単元行の `(n)` は
  **その月に配当する時数**で、残りは翌月先頭の繰越欄と一致する（4〜9月の実績で検証済み）。
  進度は前月確定版の続きから振り、年間計画上の理論値と食い違う場合は前月確定版を優先する。
- **国語の時数には書写を含む**（出力先ひな型の集計数式が
  `COUNTIF(...,"国語")+COUNTIF(...,"書写")` になっている）。
- **行事（時）の集計対象は教科名 `行事`、行事（日）は `①行事`**。

## 令和8年10月で利用者に確認が必要な点

1. 7日・14日の理科（佐藤先生）を水6へ振り替えてよいか（水2が学年の総合になったため）
2. 家庭科の7時間目を22日2校時（1組は外国語）に置いてよいか
3. 8日・22日の家庭科の下段を「舞子先生の案による」とした（交換授業でない時間のため）
4. 7日・14日の3校時が学年の学活になり、通級の算数（水3）と重なる
5. 22日5校時（小教研理科授業の時間）は1組と同じ社会にしている
6. 書写を15日・29日の木3に置いた（月2時間に対し木3は5回ある）
