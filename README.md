# 月案・時間割作成支援アプリ

小学校教員が複数のExcel・PDF資料を参照して毎月作成している「月学習予定表」を
半自動で作成するための、インストール不要のローカルWebアプリです。

- 開発の元になった指示書: 初回開発指示書（月案・時間割作成支援アプリ）
- 現在の実装段階: **フェーズA（基盤）** — 担当学級設定、ファイル取込み、
  自動解析結果の確認・対応付け、端末内保存まで実装済み。フェーズB以降
  （初期案の自動作成、単元・分科、編集・出力）は未実装です。

## このリポジトリの構成

| フォルダ | 内容 |
|---|---|
| `app/` | ソースコード（Vite + React + TypeScript）。開発はここで行います。 |
| `release/` | 教員に配布する完成品。`app/` をビルドして作った単一HTMLファイルと、Windows用の起動用バッチファイルが入っています。 |

## 教員向け：使ってみるには

`release/` フォルダを丸ごとコピーし、`起動.bat` をダブルクリックしてください。
詳しい説明は `release/使い方.txt` にあります。

## 開発者向け：続きを実装するには

`app/README.md` に、技術構成・ディレクトリ構成・既知の制約をまとめています。
`app/` で変更した後は、次の手順で `release/` を更新してください。

```bash
cd app
npm install
npm run build                       # app/dist/index.html を生成
cp dist/index.html ../release/index.html
```

`起動.bat` と `使い方.txt` は `release/` 直下にあり、通常は変更不要です。
